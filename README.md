# 🚗 Idaho Driving Test Prep (The "Dad Tool")

Live Web Tool: [0utrider.github.io/IdahoDrivingTest](https://0utrider.github.io/IdahoDrivingTest/)

A lightweight web app built to help my teenager study for the Idaho Driver’s License written knowledge exam. 

Teaching a teen to drive is terrifying enough—studying for the test shouldn't be. I originally threw this together so my kid could drill practice questions on his phone without wading through clunky state DMV PDF manuals. It worked for us, so I figured other parents and students might find it useful too!

> [!WARNING] ⚠️ Disclaimer for Fellow Parents:
>
> This tool can help your teen pass the written permit test. However, **I cannot help you survive the actual behind-the-wheel driving instruction.** White knuckles, phantom passenger-side braking, and silent prayers in church parking lots are, unfortunately, entirely on you. **Godspeed.** 🫡

## ✨ Features
- Dynamic 20-Question Quizzes: Pulls a randomized set of 20 questions from the pool every time you start.
- Shuffled Options: Both the questions and their multiple-choice answer orders are randomized to prevent rote memorization by position.
- Instant Feedback: Answers and explanations are revealed right after selection so learning happens immediately.
- Running Score Tracker: Keeps a live tally of correct/incorrect answers until the quiz is finished.
- Mobile Friendly: Clean and simple to tap through on a phone, tablet, or desktop.
